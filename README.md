## About

I build things that keep running after I stop watching them: **AI agents**, **automation** and
**developer tooling**. Most of my projects start as a throwaway script and end up as a workflow I no
longer think about.

- **Building** — AI-agent experiments, workflow automations, CLI tooling
- **Exploring** — agent frameworks, desktop / browser automation, OSS ecosystems
- **Open to** — collaborations on AI tooling and open-source experiments
